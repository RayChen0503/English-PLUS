## 執行環境與待完成的驗收

Windows 可執行 Worker、管理台、Python 工具及 Firebase 模擬器；本機沒有 Xcode，無法證明修改後的 iOS 已完成編譯、模擬器操作與真機驗證。新增 XCTest 已納入專案 target，仍須由 macOS CI 執行目前這份修正版。

macOS 應驗證新增及既有 XCTest、Firebase iOS SDK 的離線重送／重啟、快速換帳號與班級、跨午夜續做、同帳號跨裝置作答、上傳後中斷再恢復、Google／Apple 登入與真機附件。Firebase 模擬器已驗證服務端契約，但不能取代這些 iOS SDK 與裝置操作。

CI 設定使用 Node 22；本次乾淨安裝使用本機 Node 24。一般依賴安裝腳本曾被自動審查拒絕，因此依審查允許的 `--ignore-scripts` 方式安裝並完成測試，沒有手動執行被拒的安裝腳本。完整 Node 22／macOS CI 安裝仍待該環境驗證。
