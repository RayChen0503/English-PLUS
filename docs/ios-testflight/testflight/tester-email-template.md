# TestFlight Tester Email Template

Subject: English+ iOS 內測邀請

你好：

我們正在進行 English+ iOS 版本內測。English+ 是偏鄉學生雙軌學習平台，這次測試重點是確認學生、老師、志工三種角色的核心流程是否順暢。

## 安裝方式

1. 請先在 iPhone 安裝 Apple TestFlight app。
2. 開啟你收到的 TestFlight 邀請信。
3. 點選 Accept / 接受邀請。
4. 在 TestFlight 中安裝 English+。

## Role tested

請依照你被分配的角色測試：

- Student Flow Testers：學生端，測試登入、心情檢測、每日任務、練習中心、支援求助。
- Teacher Flow Testers：老師端，測試學生優先排序、求助清單、回饋回覆、報告資訊。
- Volunteer Flow Testers：志工端，測試接力任務、陪伴建議、鼓勵回覆、接力紀錄。
