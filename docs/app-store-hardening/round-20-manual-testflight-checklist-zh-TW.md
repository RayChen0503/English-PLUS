# English+ 第 20 輪 TestFlight 真機總驗收

這份清單用於驗收 English+ 1.0 的 TestFlight 候選版本。請使用至少一支 iPhone；跨裝置同步請再準備另一支 iPhone 或 iPad。每個項目都必須實際操作，不以畫面存在或編譯成功代替。

## 1. 測試紀錄

```text
TestFlight 版本／Build：
測試日期：
測試者：
裝置與 iOS／iPadOS 版本：
第二台裝置與系統版本：
學生測試帳號：
老師測試帳號：
志工測試帳號：
```

結果只使用「通過／失敗／不適用」。失敗時記錄角色、頁面、操作步驟、預期結果、實際結果、裝置、時間與截圖或錄影。閃退、資料越權、登入死循環、任務或支持跨裝置失同步一律屬於發布阻擋。

## 2. 安裝、冷啟動與帳號

- [ ] 從 TestFlight 全新安裝後，先看到身分選擇，不會直接進入學生端。
- [ ] 未登入時可開啟隱私政策與支援頁面，連結正確且可返回 App。
- [ ] 學生以 Email 建立帳號、驗證、登入與忘記密碼均可完成。
- [ ] Google 首次登入可直接建立學生帳號；再次登入不會建立重複帳號。
- [ ] Apple 首次登入可直接建立學生帳號；隱藏 Email 情境仍能完成流程。
- [ ] 同一個人連結 Google、Apple、Email 後仍是同一 UID、同一份進度。
- [ ] 登入錯誤有可理解的訊息，不顯示 Firebase、mock、endpoint 或 stack trace。
- [ ] 關閉再開 App 時工作階段符合產品設計；登出後不殘留上一位使用者資料。
- [ ] 同意畫面逐項勾選後才可繼續，已同意帳號不會每次啟動重複被攔截。
- [ ] 學生、老師、志工登入後都進入正確角色介面，不能互相越權切換。

## 3. 學生個人學習流程

- [ ] 未加入班級的學生仍可完整使用心情檢測、每日任務、自由練習、AI 與個人進度。
- [ ] 四題心情檢測的時間、挑戰意願與題型偏好會影響每日任務。
- [ ] AI 任務分析完成後直接產生可執行題組，不只顯示一段建議文字。
- [ ] 今日任務題型、難度與實際打開的題目一致。
- [ ] 答對才增加今日進度；答錯不增加，完成時有清楚的成就提示。
- [ ] 題目提交前看不到「問 AI 解題」；提交後才出現，且按鈕不會干擾送出答案。
- [ ] AI 解釋針對當前題目、學生答案與正確答案，不洩漏 API 或內部技術資訊。
- [ ] 答錯後的三題加練是獨立有限流程；完成或退出會回到原題組原進度。
- [ ] 自由練習選題頁與作答頁分離；完成或主動離開會回到選題頁。
- [ ] AI 推薦練習會打開符合建議的實際題組；找不到精確條件時採合理 fallback。
- [ ] 同一題組不連續堆疊相同答案、相同正確位置或高度重複句型。
- [ ] 學習地圖、熟練度、錯題複習與間隔複習會隨真實作答更新。
- [ ] 每日重置、延續上次進度與重新檢測三條路徑都能返回合理的下一步。

## 4. 班級與教師任務

- [ ] 老師可建立班級、重新產生加入碼、重新命名與刪除自己建立的班級。
- [ ] 學生輸入有效代碼可加入；無效、過期或舊代碼有清楚錯誤。
- [ ] 學生可加入多個班級並切換目前班級，個人學習資料不會被錯誤混入。
- [ ] 老師只能看到學生加入班級後且授權範圍內的資料。
- [ ] 老師可選學生、題組與期限指派任務；學生班級分頁即時出現紅點與任務。
- [ ] 學生按開始後打開的就是老師指定題組，不會跳到首頁或其他練習。
- [ ] 學生作答時，老師端可看到正確的部分進度、答對／答錯與完成狀態。
- [ ] 完成後學生紅點消失，老師端任務移至完成區；重新登入仍一致。
- [ ] 老師收回未完成任務後，學生端任務與紅點即時消失。
- [ ] 老師刪除班級後，所有學生與志工失去該班權限並回到合理空狀態。
- [ ] 學生離開班級後不能再讀寫班級內容，老師仍可保留合法的歷史報表。

## 5. 跨裝置真人支持

- [ ] 裝置 A 以學生送出一題完整求助，裝置 B 的老師立即收到正確題目快照。
- [ ] 求助包含題目、選項、學生答案、正確答案與必要解析，不產生空白或無意義接力。
- [ ] 老師回覆後，裝置 A 不重啟 App 即可收到；等待狀態與未讀數同步更新。
- [ ] 志工若屬於該服務班級，也能看到同一求助與老師已送出的回覆。
- [ ] 任一方回覆後，老師與志工待回覆數一致，不重複計算同一題。
- [ ] 老師或志工選擇收起後，學生仍可閱讀回覆並自行收起；沒有「已讀不回」重複功能。
- [ ] 尚未被回覆時，學生可收回求助；老師、志工項目與紅點同步消失。
- [ ] 已有回覆後不可用錯誤狀態收回；介面提供清楚的下一步。
- [ ] 同一帳號在另一台裝置登入時看到相同支持紀錄，不依賴本機快取才出現。
- [ ] 離線送出或回覆會顯示待同步／重試；恢復網路後不重複建立訊息。

## 6. 老師工作區

- [ ] 首頁只顯示目前班級的重點資訊，學生清單來自有效班級成員。
- [ ] 切換班級後學生、任務、支持與報表同步切換，不殘留上一班資料。
- [ ] 班級學生頁可查看每位學生待完成、進行中、已完成任務與題目結果。
- [ ] 接力紅點等於真正未處理件數；回覆、收起或學生收回後立即減少。
- [ ] 老師可自行撰寫回覆；AI 只產生可編輯草稿，不會未確認就送出。
- [ ] 載入、空資料、離線與錯誤都有明確狀態與重試，不顯示假資料。
- [ ] 老師不能看到未加入班級的學生或加入前的個人學習歷史。

## 7. 志工申請、管理員審核與服務範圍

- [ ] 志工註冊後清楚看到待審核狀態，未核准前不能查看學生資料。
- [ ] 可上傳最多 5 個證明、總量最多 25 MB；格式、大小與網路錯誤提示清楚。
- [ ] 管理員網站只能由已授權管理員登入，其他帳號無法查看申請與證明。
- [ ] 管理員可透過安全連結開啟每份證明，連結過期後不能再使用。
- [ ] 通過、要求補件、拒絕都必須有原因；志工端會顯示管理員寫的內容。
- [ ] 補件後可重新送審；拒絕或通過後狀態、按鈕與可操作範圍正確。
- [ ] 審核完成後證明依政策刪除，介面不再提供失效檔案。
- [ ] 核准志工只有在加入並獲准服務班級後，才能看到該班學生主動送出的求助。
- [ ] 志工不能看到完整心情、完整學習歷史或其他班級學生資料。
- [ ] 老師移除志工或志工離開班級後，求助、紅點與讀取權限立即消失。

## 8. 隱私、安全與帳號刪除

- [ ] 隱私政策、支援信箱與 App 內說明一致，第三方 AI 與未成年人界線清楚。
- [ ] App 不顯示或記錄 API key、Firebase 設定、私人證明網址與內部錯誤內容。
- [ ] 情緒資訊只提供學生主動求助入口，不假裝醫療診斷或自動通報。
- [ ] 診斷與崩潰回報預設關閉，只有明確同意後啟用，且可再次關閉。
- [ ] 帳號刪除需要二次確認；完成後不能再登入，個人資料依政策清除。
- [ ] 刪除、離班、刪班、移除志工後，以舊畫面或另一裝置都不能繼續越權操作。

## 9. UI、深色模式與無障礙

- [ ] 淺色與深色模式逐頁檢查學生、老師、志工，文字、按鈕與狀態皆清楚可讀。
- [ ] iPhone SE 等小螢幕與 Pro Max 都無重疊、截字、無法捲動或底部導覽遮擋。
- [ ] 將文字調到最大的輔助使用尺寸，登入欄位、鍵盤與主要按鈕仍可操作。
- [ ] 鍵盤可收起，Email 按下一步會移到密碼，送出按鈕不被鍵盤永久遮住。
- [ ] VoiceOver 可讀出角色、欄位、同意狀態、進度、紅點與主要動作的意義。
- [ ] 開啟「減少動態效果」後不影響導航與完成提示。
- [ ] 載入中不可重複送出；失敗後可重試；空狀態不提供看似可點但無作用的控制。

## 10. 發布判定

以下任一情況發生即停止發布並建立修正紀錄：

- [ ] 閃退、卡死、無限載入或固定可重現的導航錯誤。
- [ ] Google、Apple 或 Email 的首次建立、登入、連結、登出或刪除失敗。
- [ ] 跨裝置任務、支持、審核或權限狀態不同步。
- [ ] 任一角色可讀寫不屬於自己的學生、班級、申請或證明資料。
- [ ] AI 在作答前洩漏答案、無法執行建議、顯示內部資訊或繞過身分／額度限制。
- [ ] 深色模式、大字體或小螢幕讓主要流程無法完成。

所有適用項目通過後，記錄 TestFlight Build、測試者、裝置與日期，才可把此版本標記為 App Store 提交候選版。
